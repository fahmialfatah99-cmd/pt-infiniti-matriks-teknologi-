# PROJECT BRIEF: PT Infiniti Matriks Teknologi

## 1. TUJUAN PROYEK
Membangun website korporat modern, canggih, dan sangat interaktif untuk "PT Infiniti Matriks Teknologi" (Perusahaan Infrastruktur Jaringan FTTH). Website harus terlihat premium, futuristik, dan tidak membosankan.

## 2. ATURAN KETAT (RULES)
1. **Tech Stack:** HTML5, Tailwind CSS (via CDN atau build), Alpine.js (untuk interaktivitas ringan), dan AOS (Animate On Scroll).
2. **Desain:** Wajib Dark Mode default dengan aksen Neon Cyan/Blue (tema fiber optic). Gunakan Glassmorphism, Gradien halus, dan efek Glow.
3. **Kode:** Harus modular, bersih, dan responsif (Mobile-First).
4. **DILARANG:** Desain flat yang membosankan, teks terlalu panjang tanpa visual, dan layout yang berantakan di mobile.

## 3. FITUR CANGGIH YANG WAJIB ADA
1. **Interactive Hero:** Background dengan animasi partikel/jaringan node (gunakan canvas atau CSS murni) yang bergerak mengikuti mouse.
2. **Dark/Light Mode Toggle:** Tombol switch tema yang smooth.
3. **Live Speed Test UI:** Mockup UI tes kecepatan internet interaktif di section layanan.
4. **Scroll Animations:** Elemen muncul dengan efek fade-up, zoom, atau slide saat di-scroll (gunakan AOS).
5. **Interactive Pricing/Package Slider:** Slider kartu paket internet yang bisa digeser.
6. **Floating Action Button (FAB):** Tombol WhatsApp/Chat yang melayang dengan efek pulse.

## 4. STRUKTUR HALAMAN (SECTION BY SECTION)
1. **Navbar:** Sticky, glassmorphism, logo, menu, dan tombol Dark Mode.
2. **Hero:** Headline futuristik, sub-headline, CTA ganda, dan animasi background.
3. **Stats Counter:** Angka statistik (Klien, KM Kabel, Uptime) yang berjalan (counting up) saat di-scroll.
4. **Layanan (Services):** Grid kartu dengan hover effect 3D tilt.
5. **Speed Test UI:** Mockup visual tes kecepatan yang menarik.
6. **Paket Harga:** Slider/karusel paket FTTH.
7. **Testimoni:** Carousel review klien.
8. **FAQ Accordion:** Pertanyaan umum dengan animasi buka-tutup.
9. **Kontak & Footer:** Form kontak validasi, peta lokasi (mockup), dan link sosial media.
